Hospital Management

Complete clinic workflow inside Odoo

Manage doctors, patients, diseases, visits and reporting in one module. Built for small clinics and training hospitals.

Key features

  • Doctors with qualifications, intern/mentor relations, kanban grouped by category.
  • Patients with personal-doctor history, insurance, medical attributes (blood type, gender, age).
  • Visits with state machine (Planned / Completed / Cancelled), calendar / pivot / graph / search views and searchpanel.
  • Diseases as a hierarchical classifier with searchpanel filtering.
  • Wizards: mass reassign personal doctor; visit report; monthly disease report (with grouping by disease).
  • PDF report for a doctor: visit history with colored statuses + patients table.
  • Security: cascading groups (Patient → Intern → Doctor → Manager → Administrator) with record rules per visit.
  • i18n: Ukrainian translation included.
